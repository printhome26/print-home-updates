# Print Home App News Design – Test-App

Gleiche Funktionen wie die aktuelle Print Home App (Version 2.0), neue Farbwelt im Nordic-Stil des Shops:

| Rolle | Farbe |
|---|---|
| Hintergrund (Birke) | `#EFEAE0` |
| Schrift, Buttons, Rahmen (Nordic-Blau) | `#17232F` |
| Akzent (Salbei) | `#4F7564` |
| Flächen (Sand) | `#E2E2DA` / `#E9E7DF` |

Dateien: `index.html` und `app.js` gemeinsam auf einen HTTPS-Webspace laden, dann `index.html` öffnen.

## Testen
- Demo-Modus: echte Produkte aus print-home.com, Checkout noch inaktiv.
- Über GitHub Pages: Repo → Settings → Pages → Branch `main`, Ordner `/ (root)` → dann `…/print-home-app-news-design/` öffnen.
